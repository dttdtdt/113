# 角色系统总览

> 记录角色的基本构成、初始配置及其在一局游戏中的延续规则。

## 玩家与角色

每名玩家在一局游戏中仅操作一个角色，角色各自持有职业、专长、装备、卡牌、属性与状态。

角色在一局游戏开始时建立，仅存在于本局之中。本局结束后，该角色的生命周期随之结束，不延续至下一局。

## 职业与专长

开局时，玩家在特殊起始节点选择一个初始职业。职业天赋点可用于解锁其他职业、推进天赋链或获取已开放的职业牌。

所有角色在开局时拥有全部专长，初始均为 1 级。专长侧重探索，随相关行动积累熟练度而成长。具体定位与成长方式见[职业与专长设计](./02-职业与专长设计.md)。

## 初始装备与卡牌

完成初始职业选择后，角色获得该职业提供的初始装备。

所有角色开局各自获得一套相同的基础通用牌。其他初始战斗卡牌按来源规则进入战斗卡组。探索时，角色可以使用常驻行动牌与个人持有的物品卡。

装备的归属、使用条件、收益及槽位强化见[装备设计](./03-装备设计.md)。

## 卡牌管理

战斗卡牌的移除与强化权限由其来源绑定规则决定。

战斗卡组内的卡牌按战斗规则参与对局，玩家不能主动停用。卡组展示与管理规则见[卡牌共通生命周期](../card-system/01-卡牌共通生命周期.md)。

## 属性与状态的延续

角色在阶段、节点及区域切换时沿用当前属性与状态。体力、生存状态与两种能量的规则见[属性与状态设计](./01-属性与状态设计.md)。

## 死亡与复活

角色死亡后仍保留在当前队伍中，可以在满足条件后复活。复活前，该角色无法参与探索与战斗，也无法使用或操作自己的卡牌。

单个角色死亡不会立即结束本局游戏。若己方所有玩家角色均死亡，本局游戏失败结束。

> 复活条件及复活后角色的属性与状态尚未确定。
