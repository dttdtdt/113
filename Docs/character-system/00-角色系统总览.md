# 角色系统总览

> 记录角色的基本构成、初始配置及其在一局游戏中的延续规则。

## 玩家与角色

每名玩家在一局游戏中仅操作一个角色。角色独立持有属于自己的职业、专长、装备、卡牌、属性与状态。

角色仅存在于当前一局游戏中。一局游戏开始时建立角色，本局结束后，该角色的生命周期随之结束，不作为同一个角色延续至下一局。

## 职业与专长

角色可以拥有多个职业和多个专长。开局时，玩家在特殊起始节点为角色各选择一个职业和专长。

职业侧重战斗，提供属性影响与战斗功能；专长侧重探索，提供属性影响、探索功能及战斗辅助。具体定位与成长方式见《01-职业与专长设计》。

每个职业与专长分别拥有一条天赋链。开局选择时直接解锁对应天赋链的节点0，后续通过投入相应类别的天赋点解锁更多职业、专长或推进已有天赋链。

## 初始装备与卡牌

完成职业与专长选择后，角色根据所选内容获得对应的初始装备。

角色的初始卡牌由职业、专长及初始装备按照各自规则提供。卡牌的归属、使用范围及后续流转遵循卡牌系统的相关规则。

> 初始装备的具体配置由职业、专长和装备系统确定。

## 属性与状态的延续

角色在整局游戏中共用同一套属性与状态。战斗与探索阶段切换，以及节点和区域切换，均延续角色当前的属性数值与状态。

属性与状态可以在游戏过程中发生变化，但不会仅因阶段或节点切换而默认清除或重置。状态的移除、重置及其他变化，由状态自身规则或相关系统效果决定。

> 属性的具体项目、初始数值及各类状态的生效规则留待后续设计。

## 死亡与复活

角色死亡后仍保留在当前队伍中，并存在被复活的可能。复活前，该角色无法参与探索与战斗，也无法使用或操作自己的卡牌。

单个角色死亡不会立即结束本局游戏。若己方所有玩家角色均死亡，本局游戏失败结束。

> 复活条件，以及复活后角色的属性与状态尚未确定。
