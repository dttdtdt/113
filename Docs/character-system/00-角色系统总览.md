# 角色系统总览

> 记录角色的基本构成、初始配置及其在一局游戏中的延续规则。

## 玩家与角色

每名玩家在一局游戏中仅操作一个角色，角色各自持有职业、专长、装备、卡牌、属性与状态。

角色在一局游戏开始时建立，仅存在于本局之中。本局结束后，该角色的生命周期随之结束，不延续至下一局。

## 职业与专长

角色可以同时拥有多个职业与专长。开局时，玩家在特殊起始节点各选择一个职业和专长。

职业侧重战斗，提供属性影响与战斗功能；专长侧重探索，提供属性影响、探索功能及战斗辅助。具体定位与成长方式见《02-职业与专长设计》。

每个职业与专长均拥有独立的天赋链。开局选择直接解锁对应天赋链的节点0；后续通过投入对应类别的天赋点，解锁更多职业、专长或推进已有天赋链。

## 初始装备与卡牌

完成职业与专长选择后，角色根据所选内容获得对应的初始装备。

角色的初始卡牌由职业、专长及初始装备按各自规则提供。卡牌的归属、使用范围及流转方式遵循卡牌系统规则。

> 初始装备的具体配置由职业、专长和装备系统确定。

装备的归属、穿戴条件、收益及槽位强化方式见《03-装备设计》。

## 属性与状态的延续

每个角色在整局游戏中使用同一套属性与状态。战斗与探索阶段、节点及区域发生切换时，均延续角色当前的属性数值与状态。

属性与状态可以在游戏过程中发生变化，但不会仅因阶段或节点切换而默认清除或重置。状态的移除、重置及其他变化，由状态自身规则或相关系统效果决定。

属性的暂定用途、影响来源及状态规则见《01-属性与状态设计》。

## 死亡与复活

角色死亡后仍保留在当前队伍中，可以在满足条件后复活。复活前，该角色无法参与探索与战斗，也无法使用或操作自己的卡牌。

单个角色死亡不会立即结束本局游戏。若己方所有玩家角色均死亡，本局游戏失败结束。

> 复活条件及复活后角色的属性与状态尚未确定。
