# 装备设计

> 记录装备的持有、穿戴、卡牌关联及槽位强化规则。

## 装备持有

角色根据开局选择的职业与专长获得初始装备，后续解锁职业不额外提供初始装备。

装备归角色个人持有，存放于容量无限的个人仓库，不在角色之间共享或转交。

装备可以更换。卸下的装备保留在个人仓库中，后续可以重新装备。

不再需要的装备可以在商店或满足特定条件的事件中出售。

## 装备槽位与穿戴条件

角色拥有三个装备槽位：主手、副手和通用槽位。

主手与副手均用于穿戴武器，可以同时装备同款武器；通用槽位可以穿戴武器以外的所有装备。

装备不设职业限制，所有角色均可按槽位类型穿戴。装备属性对不同玩法形成搭配倾向，具体装备组合由玩家自主决定。

装备之间不设置套装或特定组合触发的额外效果。

> 是否存在同时占据主手与副手的装备，留待后续设计。

## 穿戴收益与卡牌

装备在穿戴时提供属性、卡牌、状态或特殊机制。卸下时，移除依赖穿戴生效的持续性收益。

装备提供的卡牌与装备绑定：穿戴时，符合条件的卡牌自动进入战斗卡组；卸下时，关联卡牌离开卡组。

装备卡牌不进入探索卡组，装备带来的属性与状态变化仍可影响探索。

装备卡牌在战斗中不升级，消耗、冷却等状态按当前战斗的卡牌规则处理，不作为跨关卡的使用限制延续。

## 换装时机

换装仅能在非事件状态下进行，战斗中不开放。

## 槽位强化与品质

角色通过更换装备调整搭配，通过槽位强化提升装备的生效品质。

槽位强化在提供对应功能的特定事件中进行，每个槽位具有强化次数上限。强化投入保留在槽位上，不受换装影响。

装备未穿戴时不区分品质。穿戴后，根据所在槽位的强化程度，采用对应品质的配置生效。

各品质对应的装备属性与卡牌内容由策划预先配置。

> 品质划分、槽位强化次数上限、强化消耗及各品质的具体配置留待后续设计。
