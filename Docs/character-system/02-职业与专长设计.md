# 职业与专长设计

> 记录职业与专长的功能定位、卡牌来源及成长规则。

## 功能定位

职业侧重战斗，提供属性影响与战斗功能，不承担探索辅助的定位，也不提供探索卡牌。

职业设计侧重角色个人的战斗方式与构筑差异，不强调固定的队伍职能分工。玩家可以深入发展单个职业，也可以组合多个职业，形成不同的战斗玩法。

专长侧重探索，提供属性影响、探索功能及战斗辅助。专长卡牌可以仅用于战斗、仅用于探索，也可以同时用于两个阶段，具体使用范围由卡牌自身规则决定。

职业与专长均可影响角色属性。每个角色在整局游戏中使用同一套属性，其变化可以影响卡牌效果及角色在战斗、探索中的表现。职业带来的属性变化可能间接影响探索，但职业不提供探索卡牌。

## 卡牌来源

卡牌来源与跨阶段使用遵循卡牌系统规则：

- 战斗卡组可以包含来自职业、专长、装备及其他获取途径的卡牌；
- 探索卡组可以包含来自专长及其他获取途径的卡牌；
- 同时用于战斗与探索的卡牌共享归属与状态，并在两个阶段保持相同效果。

## 经验与天赋点

职业与专长采用相同的天赋链成长模板，但分别积累和使用各自的经验与天赋点。

对每个角色而言，所有职业共用一条职业经验条，获得的职业天赋点可投入任意职业；所有专长共用一条专长经验条，获得的专长天赋点可投入任意专长。

经验达到相应要求后，角色获得对应类别的天赋点。玩家可以自主决定将点数用于发展已持有的职业、专长，或解锁新的职业、专长。

> 各阶段的经验需求尚未确定。

## 经验获取

职业与专长经验的获取途径包括：

- 在战斗与探索中完成行为相关任务，获得职业或专长经验；
- 通过探索过程中的奖励等途径获得经验；
- 离开战斗节点时获得定值职业经验，离开探索节点时获得定值专长经验。

成长任务不受职业与专长的功能侧重限制。职业任务可以要求探索行为，专长任务也可以要求战斗行为，使战斗与探索相互支持。

> 任务内容及具体奖励规则留待后续设计。

## 天赋链

每个职业与专长均拥有独立的天赋链，按单线顺序推进，并分别记录节点解锁进度与天赋选择。

### 节点0：解锁职业或专长

节点0用于解锁对应的职业或专长，具体收益如下：

- 初始选择的职业：获得对应的初始装备、卡牌、基础天赋和任务；
- 后续解锁的职业：获得对应的卡牌和任务，不获得该职业的初始装备与基础天赋；
- 专长：无论初始选择还是后续解锁，均获得对应的卡牌、基础天赋和任务。

节点0直接提供的天赋称为基础天赋，与后续节点的三选一天赋区分。后续解锁的职业仍可正常推进天赋链，获得后续节点的天赋。

开局时，玩家各选择一个职业和专长，直接解锁对应天赋链的节点0。后续获得更多职业或专长时，消耗相应类别的天赋点解锁其节点0。

所有职业与专长均可供玩家选择。拥有足够的对应类别天赋点，即可解锁任意尚未持有的职业或专长，无须先通过探索、事件等途径发现。

### 后续天赋节点

后续天赋节点须按前置顺序逐个解锁，并消耗对应类别的天赋点。

每个节点提供三个天赋，玩家从中选择一个。节点内的选择不改变后续路线，玩家继续沿同一条天赋链推进。

天赋收益可以包括新增卡牌、强化符合条件的已有卡牌、提升属性，以及提供特殊机制或被动效果。

> 天赋链长度、各节点的点数消耗、具体天赋内容及点数能否重新分配，暂时待定。
