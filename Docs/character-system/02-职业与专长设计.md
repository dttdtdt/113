# 职业与专长设计

> 记录职业与专长的功能定位、卡牌来源及成长规则。

## 职业

职业通过职业牌、被动天赋及通用牌的附加效果形成战斗构筑差异。职业带来的属性变化也可能间接影响探索表现。

玩家可以深入发展单个职业，也可以兼修多个职业，将各职业的卡牌和天赋组合进同一套打法。

### 职业经验与天赋点

每个角色的所有职业共用一条职业经验条。经验达到要求后，角色获得职业天赋点，可用于解锁职业、推进天赋链或获取职业牌。

职业经验的获取途径包括：

- 在战斗或探索中完成职业任务；
- 通过探索过程中的奖励等途径获得经验；
- 离开战斗节点时获得定值职业经验。

> 经验需求、任务内容及具体奖励规则留待后续设计。

### 天赋链

每个职业拥有独立的天赋链，按单线顺序推进，并分别记录节点解锁进度与天赋选择。

#### 节点 0

节点 0 用于解锁职业。无论是初始选择还是后续解锁，角色都立即获得该节点的天赋与对应职业任务。初始选择的职业还提供初始装备。

开局时，玩家选择一个初始职业，直接解锁对应天赋链的节点 0。后续可消耗职业天赋点解锁任意尚未持有的职业。

#### 后续天赋节点

后续天赋节点须按前置顺序逐个解锁，并消耗职业天赋点。

每个节点提供三个选项，玩家从中选择一项。选项可以提供职业牌或被动天赋。节点内的选择不改变后续路线，玩家继续沿同一条天赋链推进。

选中职业牌后，角色立即将一张该牌加入战斗卡组，并将该牌开放给该职业的天赋点候选池。候选池只收录通过天赋节点实际选中的职业牌。

部分节点天赋会为指定通用牌追加效果。同一张通用牌可以同时获得多个职业天赋赋予的效果，各效果按自身条件生效。

### 消耗天赋点获取职业牌

玩家先指定一个候选池中有牌的已解锁职业。确认消耗天赋点后，立即扣点，并从该职业的候选池随机给出一组卡牌。

每次消耗天赋点获取职业牌时，可刷新一次候选。玩家最终可以选择一张牌加入战斗卡组，也可以放弃。放弃时不退还已消耗的天赋点。

### 通过奖励或商店获取职业牌

战斗节点奖励、探索奖励和商店可按各自配置提供已解锁职业的牌，包括尚未通过天赋链开放的职业牌。获得的牌直接加入战斗卡组，其是否进入天赋点候选池仍由天赋节点的选择决定。

> 天赋链长度、天赋点消耗、每组候选数量、刷新时能否重复出现原候选，以及点数能否重新分配，留待后续设计。

## 专长

角色开局即拥有全部专长，初始均为 1 级。角色执行相关行动时积累对应专长的熟练度，达到升级条件后提升该专长等级。各项专长独立记录熟练度与等级。

专长扩展已有的探索行动，可改变行动代价、结果或产物用途，也可解锁高级配方。推进探索所需的关键交互应提供无需特定专长等级即可完成的途径。探索行动与合成规则见[探索与生存设计](../game-flow/02-探索与生存设计.md)。

专长也可按具体设计提供属性收益或战斗辅助。专长提供的战斗卡牌遵循[战斗卡组规则](../card-system/01-卡牌共通生命周期.md)。

> 具体专长、熟练度获取条件与升级要求留待后续设计。
