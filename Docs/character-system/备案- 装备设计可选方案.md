# 装备设计可选方案

> 记录装备系统的候选方案、评估与方案专属问题，三个方案均未确定采用。系统关联、设计要点与共通问题见《03-装备设计》。

## 方案一：多槽位换装与组合

### 当前设想

- 装备可以更换，卸下后保留并可再次装备；
- 队伍拥有共享装备仓库；
- 装备槽位较多，至少五个；
- 装备不在原基础上直接升级；若存在升级，则表现为转化成另一件装备，或保留在槽位上的强化效果；
- 以装备组合或套装效果形成构筑，主要通过获得更多、更好或更适配的装备实现成长；
- 装备掉落随流程推进而提升，玩家根据当前卡组调整搭配。

### 评估

该方案最突出获得新装备后的搭配与替换。旧装备能够保留和共享，有助于后续转向构筑，也能让一次掉落对队伍中的不同角色产生价值。

主要难点是套装过渡与管理量。如果新装备单件更强却会破坏已有套装，奖励可能长期无法使用；如果后续装备在数值上全面替代旧装备，早期的搭配也可能失去保留价值。较多槽位与共享库存还会增加比较、整理和讨论的频率。

制作成本主要集中在装备种类、掉落梯度、组合效果和库存交互。装备不直接升级，仍可能需要制作大量不同阶段的装备内容。

### 待明确问题与建议

1. “套装”是固定装备凑齐后触发效果，还是通过装备标签、效果配合自由组成？它们对掉落需求和搭配自由度的影响不同。
2. 后期装备主要提高数值，还是提供不同的玩法与适配方向？旧装备准备保留多久的使用价值？
3. 多槽位分别承担什么选择？是否需要五个以上槽位才能表达这些差异？
4. 装备转化与槽位强化是否实际采用，还是仅作为后续可扩展方向？

> 建议：优先验证少量装备能否形成顺畅的替换与组合过程，再扩展槽位和套装数量。尤其需要检查套装未凑齐时，新装备是否仍有独立价值。

## 方案二：固定装备与组件改造

### 当前设想

- 初始装备在本局内不被其他装备替换；
- 装备槽位数量暂未确定；
- 通过镶嵌、锻造、强化等方式提升或配置装备的属性、功能与特性；
- 装备相关掉落主要为强化道具或改造组件；
- 将装备能力拆分为可配置内容，由玩家逐步组合；
- 改造存在容量或类型限制，例如每件装备的卡牌槽只能配置一个提供卡牌的组件，具体规则待定。

### 评估

该方案强调持续改造同一套装备，能够减少换装导致的投入损失，也便于让初始装备保持长期存在感。玩家的构筑选择转移到组件配置、改造方向与投入分配上。

主要难点是改造是否真正形成取舍。如果收益都能持续累加，玩法容易变成获得资源后不断强化；如果组件不可替换，后续转向构筑又可能受到限制。固定装备的基础限制还可能影响多职业搭配，需要明确新职业能否利用这套装备。

该方案未必更省制作成本。装备本体数量可能减少，但组件种类、组合规则及改造界面仍需要独立设计。

### 待明确问题与建议

1. 初始装备保留哪些固定特性，哪些能力可以通过改造改变？
2. 组件能否卸下、替换或回收？旧改造的资源投入如何处理？
3. 改造的限制来自容量、类型、互斥关系还是资源消耗？
4. 强化道具与组件能否在队伍中共享？固定装备本体与可转移组件需要分别确定规则。
5. 转向其他职业的玩法时，固定装备是否能提供足够的调整空间？

> 建议：先明确装备本体与组件分别负责什么，再决定槽位数量。如果装备本体几乎没有固定特征，实际的构筑主体就会是组件，文档和界面也应围绕组件组织。

## 方案三：三件装备换装与单件升级

### 当前设想

- 装备可以更换，卸下后保留并可共享；
- 装备槽位为三个，角色同时最多装备三件装备；
- 通过更换装备实现成长，同时提供单件装备的升级途径；
- 单件升级可以采用锻造、品质提升等形式，具体方式待定。

### 评估

三件装备将搭配集中在较少的选择上，便于玩家比较整套配置，也能减少角色当前穿戴内容的管理量。相比多槽位方案，每件装备更有机会表达清晰的属性、卡牌或机制方向。

槽位有限也会强化取舍。三个槽位占满后，新装备必须替换其中一件才能生效，获得新能力时需要考虑失去的收益。对多职业角色而言，装备需要支持当前最重视的玩法，未必能同时照顾所有职业。

三件装备并不必然限制构筑深度，深度可以来自单件装备之间的配合，以及它们与职业、专长和卡牌的联系。但若某件装备独自提供过于全面的收益，它更容易成为固定选择，压缩其余装备的使用空间。

若装备承担较多卡牌来源，更换其中一件可能同时改变一组卡牌，使构筑转向更明显，也可能使过渡更困难。需要明确单件装备提供的卡牌规模，以及三件装备合计在角色卡组中占据的作用。

单件升级能够让适配当前构筑的装备继续使用，但同时存在两项决策：是否更换装备，以及资源应投入哪件装备。如果升级投入难以回收，玩家可能因为已有投入而拒绝新掉落；若换装与升级始终只增加同类数值，两种成长方式又会相互重复。

在相同的升级规则下，三件装备能减少当前配置需要逐件培养的数量，但不能据此判断整体制作成本更低。装备种类、共享库存、升级资源与跨职业组合仍需设计和验证，背包管理量也取决于保留规则与掉落数量。

### 待明确问题与建议

1. 三个槽位是否区分类型，各自承担什么作用？是否允许自由组合或重复装备？
2. 单件装备与三件装备合计分别提供多少卡牌和功能，才能既有影响力，又不使一次替换过度改变构筑？
3. 换装和单件升级分别主要改变什么？属性、卡牌和特殊效果如何分工？
4. 品质提升只增加数值，还是会改变卡牌、功能或可用改造空间？
5. 是否存在套装效果？如果凑齐三件才能触发，是否会占满全部槽位并限制替换？本方案尚未确定采用套装。

> 建议：先验证三件装备各有明确用途，以及单件替换能否顺畅改变玩法。可考虑换装主要改变适配方向，升级主要维持当前装备的可用强度；投入归属与继承规则仍需按《03-装备设计》中的共通问题确定。

## 综合比较与当前建议

三个方案分别突出不同的成长体验：

- 方案一：获得装备、比较搭配、调整组合；
- 方案二：获得组件、持续改造、配置固定装备；
- 方案三：在三件装备的配置中，取舍玩法适配与单件培养。

方案一采用至少五个槽位，侧重多件装备的组合与替换；方案三采用三个槽位，同时保留单件升级。方案三的当前穿戴管理更集中，单个槽位的取舍更突出，但需要通过单件特性与系统配合支撑构筑深度。

若希望装备掉落经常带来构筑变化，方案一与方案三更直接；若希望玩家逐步塑造并长期保留自己的装备，方案二更集中。三件装备让方案三更容易逐件审视和比较，但仍需证明换装与升级各有作用，不能仅凭槽位少就判定它更优。

结合当前多职业、卡牌来源绑定和不强调固定队伍分工的方向，建议优先比较两件事：新职业加入后装备能否顺畅适配，以及装备变化能否带来值得考虑的卡组变化。三种方案均可支持这些目标，现阶段不据此确定最终方案。
