# 职业与专长设计

> 记录职业与专长的功能定位、卡牌来源及成长方式。

## 功能定位

职业侧重战斗，提供属性影响与战斗功能，不承担探索辅助的定位，也不提供探索卡牌。

专长侧重探索，提供属性影响、探索功能及战斗辅助。专长提供的卡牌可以仅用于战斗、仅用于探索，也可以同时用于两个阶段，具体使用范围遵循卡牌自身规则。

职业与专长均可影响角色属性。角色在整局游戏中共用同一套属性，属性变化可以影响卡牌效果及角色在战斗、探索中的表现。职业带来的属性变化可能间接影响探索，但不因此成为探索卡牌的来源。

## 卡牌来源

职业与专长提供卡牌时，遵循卡牌系统已确定的来源规则：

- 战斗卡组可以包含来自职业、专长、装备及其他获取途径的卡牌；
- 探索卡组可以包含来自专长及其他获取途径的卡牌；
- 同时用于战斗与探索的卡牌共享归属与状态，并在两个阶段保持相同效果。

## 经验与天赋点

职业与专长采用相同的天赋链成长模板，分别使用职业经验与职业天赋点、专长经验与专长天赋点。

每个角色的所有职业共用一条职业经验条和一份未投入的职业天赋点；所有专长共用一条专长经验条和一份未投入的专长天赋点。两类成长资源分别积累与使用。

经验达到相应要求后，角色获得对应类别的天赋点。玩家可以自主决定将点数投入哪个已持有的职业或专长，也可以用于解锁新的职业或专长。

> 各阶段的经验需求尚未确定。

## 经验获取

玩家可以通过以下途径推动职业与专长成长：

- 在战斗与探索中完成行为相关任务，获得职业或专长经验；
- 通过探索过程中的奖励等途径获得经验；
- 离开战斗节点时获得定值职业经验，离开探索节点时获得定值专长经验。

职业与专长的功能侧重不限制其成长任务的发生阶段。职业成长任务可以要求探索行为，专长成长任务也可以要求战斗行为，使战斗与探索相互支持。

> 任务内容及具体奖励规则留待后续设计。

## 天赋链

每个职业与专长分别拥有一条独特的天赋链。天赋链按单线顺序推进，每条链独立记录已解锁节点及对应的天赋选择。

### 节点0：解锁职业或专长

节点0为职业或专长的解锁节点。解锁后，角色获得对应的职业或专长，具体收益如下：

- 初始选择的职业：获得对应的初始装备、卡牌、基础天赋和任务；
- 后续解锁的职业：获得对应的卡牌和任务，不获得该职业的初始装备与基础天赋；
- 专长：无论初始选择还是后续解锁，均获得对应的卡牌、基础天赋和任务。

基础天赋指节点0直接提供的天赋，与后续节点中选择的天赋分别记录。后续解锁的职业仍可正常推进天赋链，获得后续节点的天赋。

开局时，玩家各选择一个职业和专长，直接解锁对应天赋链的节点0。后续获得更多职业或专长时，消耗相应类别的天赋点解锁其节点0。

所有职业与专长均可供玩家选择。只要拥有足够的对应类别天赋点，玩家即可解锁任意尚未持有的职业或专长，无须先通过探索、事件等途径发现。

### 后续天赋节点

节点0之后的天赋节点需要按照前置顺序逐个解锁，并消耗相应类别的天赋点。

每个节点提供三个天赋，玩家从中选择一个。节点内的选择不改变后续路线，玩家继续沿同一条天赋链推进。

天赋的收益可以包括新卡牌、已有卡牌的强化、属性提升、特殊机制或被动效果。

> 天赋链长度、各节点的点数消耗、具体天赋内容及点数能否重新分配，暂时待定。
