# 探索阶段卡牌生命周期

> 记录探索行动牌与物品卡的开放、携带和使用规则。

## 常驻行动牌

常驻行动牌是玩家选择探索行动的入口。每个角色都可以使用，行动牌无需抽取，使用后仍可再次选择。

玩家只能为自己控制的角色发起行动。每次行动的可用性取决于场景目标、角色状态和剩余探索能量，采集还受资源点剩余次数限制。行动结果按[探索与生存设计](../game-flow/02-探索与生存设计.md)处理。

## 个人物品卡

合成获得的物品卡由合成者个人携带，不能在角色之间转移。持有者可以直接选择并使用符合当前场景条件的物品卡，效果可作用于自身或队伍。

物品卡设有个人携带上限。食物以有保质期的物品卡携带。

物品卡的可用阶段由卡牌规则决定。允许在战斗和探索中使用的物品卡，在两个阶段沿用同一份持有与使用状态，效果保持一致。

> 物品卡的容量、计数方式、叠放、过期处理及战斗中的使用入口留待后续设计。
