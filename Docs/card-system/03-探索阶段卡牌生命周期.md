# 探索阶段卡牌生命周期

> 记录卡牌在探索场景中的开放、抽取与使用规则。

## 场景开放

不同的探索场景可以开放各自对应的探索卡牌。

## 探索回合

每个探索回合开始时，各角色分别收集当前可以参与抽取的探索卡牌，重新洗牌并组成自己的探索抽牌池。

探索抽牌池建立后，向对应角色持续发牌，直至其手牌位达到上限或抽牌池为空。

探索回合中，角色每使用一张探索卡牌，便从自己的探索抽牌池中抽取一张卡牌。抽牌池为空后，本回合不再抽取。

下一个探索回合开始时，各角色重新收集可以参与抽取的探索卡牌并再次洗牌。已经消耗、处于冷却或暂时失效的卡牌是否参与洗牌，由其当前状态决定。

卡牌效果、Buff、天赋、装备或其他系统可以发起额外抽牌，也可以改变抽牌数量、时机或选取方式。

## 使用权限

探索卡牌均由玩家主动使用，不会自动触发使用行为。

每个角色只能使用自己探索卡组中符合场景及使用条件的卡牌，不能使用其他角色的卡牌。

## 关联共通生命周期

探索卡牌的使用范围、使用后处理及状态变化遵循卡牌共通生命周期。
