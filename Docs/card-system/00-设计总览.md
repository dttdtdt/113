# 卡牌系统设计总览

每个角色拥有自己的战斗卡组。战斗开始时，符合条件的卡牌进入抽牌池，随后按战斗规则抽取、使用和流转。探索时，玩家通过常驻行动牌选择行动，并可按使用条件直接使用个人持有的物品卡。

- 战斗卡组的来源、归属、获取与管理见[卡牌共通生命周期](./01-卡牌共通生命周期.md)。
- 单次战斗中的卡牌池、抽牌及使用后去向见[战斗阶段卡牌生命周期](./02-战斗阶段卡牌生命周期.md)。
- 常驻行动牌与个人物品卡的使用规则见[探索阶段卡牌生命周期](./03-探索阶段卡牌生命周期.md)。

> 卡牌强化的保留时长、卡牌替换途径，以及跨局卡牌收藏与保留规则留待后续设计。
