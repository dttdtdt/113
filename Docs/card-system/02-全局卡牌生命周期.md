# 全局卡牌生命周期

> 记录卡牌在一次完整游戏流程中的来源、归属与变化规则。

## 全局流程边界

全局流程随一局完整游戏开始，并在己方所有玩家角色死亡时结束。

## 角色卡组

每个角色各自拥有战斗卡组和全局卡组，两套卡组均归属于角色个人，不设置队伍共享卡组。

战斗卡组可以包含来自职业、专长、装备及其他获取途径的卡牌；全局卡组可以包含来自专长及其他获取途径的卡牌。

专长卡牌分为专长战斗卡牌和专长全局卡牌，分别进入战斗卡组和全局卡组。

## 获取与进入卡组

角色当前职业、专长或装备提供的卡牌会自动进入对应卡组。

部分获取途径允许玩家决定是否获取卡牌。确认获取后，卡牌自动进入对应卡组，无需再次选择是否组入。

当奖励指定卡牌的来源类别时，角色只能从自身对应的可获取卡池中获得卡牌。卡牌归属于获得它的角色，不会进入其他角色或队伍共享的卡组。

战斗卡组和全局卡组均没有容量上限。

## 来源变化

职业、专长或装备提供的卡牌与其来源绑定。只有来源有效时，相应卡牌才能留在角色的对应卡组中。

角色更换职业、专长或装备时，与原来源绑定的卡牌离开对应卡组，新来源中满足获得条件的卡牌自动进入对应卡组。

角色更换职业或专长时，原来源的天赋树进度不会保留。重新获得该来源时，从初始状态重新结算能够获得的卡牌。

重新获得曾经拥有的装备时，根据该装备的当前状态重新结算卡牌。

## 全局卡牌的使用

全局卡牌不能在战斗中使用。不同的非战斗场景可以分别开放相应的可用卡牌。

每个角色只能主动使用自己全局卡组中符合场景及使用条件的卡牌。全局卡牌不会自动触发，角色也不能使用其他角色的卡牌。

全局卡牌使用后，可以继续保留、暂时失效或离开本次全局流程，具体处理方式由卡牌自身规则决定。
