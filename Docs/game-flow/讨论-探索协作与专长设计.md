# 探索协作与专长设计讨论稿

> 本文提供一版探索与专长的设计设想，供组内讨论可行性。探索方式和专长接入方式可分别调整或替换，场景与卡牌仅用于说明。

## 讨论背景

如果交互资格取决于专长，节点内容就要同时兼顾地图主题和队伍的专长搭配。玩家在地图主题公开前选择专长，进入同一个节点后，有人可能有多种交互机会，有人却缺少可做的事。用途过窄的专长牌也可能因当前没有适用对象而滞留在手中。

即使每个人都有牌可打，探索仍可能只是各自行动。这版设想希望让队伍结合各玩家手中的牌和剩余探索资源，商量先做什么、由谁行动，以及是否继续探索。

## 本方案的设计原则

1. **各自出牌，共同决定探索路线。** 玩家使用相同来源的基础牌，各自拥有抽牌池和手牌，只操作自己的牌。
2. **用有限的资源分担行动。** 同一项交互可能有多名玩家能做。队伍根据各自的手牌与剩余探索资源安排顺序和分工，决定谁先行动、谁留牌应对后续，以及什么时候离开。
3. **专长扩展基础行动。** 专长可以改变行动代价、效果或产物用途。关键交互应保留不依赖专长的完成途径，让没有对口专长的玩家也能参与并推进探索。

## 探索方式参考：通用基础牌与节点交互

节点的交互对象、风险和收益随地图主题变化。一个节点可以同时有可调查的线索、可采集的材料，以及挡住后续路径的障碍。队伍可以处理其中一部分，也可以投入更多探索资源继续深入。

通用基础牌对应跨场景都可能用到的行动。例如：

- **调查**：了解物件、路径或线索，帮助队伍判断风险与收益。
- **采集**：取得场景中的材料，用于当场消耗或后续处理。
- **清理**：移开障碍或改变物件状态，开放后续交互。

同一类牌可以处理不同主题下的对象，具体结果由场景决定。如果某张牌暂时没有适用对象，还需要考虑玩家能否转向其他有意义的交互。

### 节点示意：雨后的林地

队伍在林地入口发现了药草和动物足迹，通往深处的路被倒木挡住。队伍可以采完药草就离开，也可以先调查足迹，再决定是否值得花费手牌和探索资源清开倒木。

即使两人都有「调查」，也不一定谁出都一样。如果其中一人还握有「清理」并需要留足资源处理倒木，另一人就可以先调查。单人面对同样的路线取舍，只需在自己的手牌和资源之间分配。

## 专长方式参考：调整基础行动及其结果

在这版设想中，专长作用于已有的探索牌或行动结果，可以提供以下变化：

- **行动代价**：在特定情境下降低消耗，为后续行动保留资源。
- **行动结果**：提供不同于基础结果的可选效果，供队伍按当前目标取舍。
- **产物用途**：增加材料的处理方式，让即时使用与留作后用都成为选项。

### 专长示意：植物学

沿用林地节点，所有玩家都可以用「采集」取得药草。拥有植物学专长的玩家打出同一张牌时，可以直接采药，也可以选择保留部分种子供后续使用。

如果队伍急需药草，可以由手牌和资源更合适的玩家直接采集；如果看重种子的后续用途，再考虑由有专长的玩家处理。即使队伍没有植物学专长，采集和继续探索也不受阻。

## 组内讨论议题

1. **先看探索本身。** 不考虑专长时，节点是否有值得队伍共同决定的事？哪些交互可以用通用基础牌表达，哪些应由场景提供？手牌暂时无法使用时，玩家还有什么选择？
2. **再看资源取舍。** 探索行动适合消耗什么资源？怎样让先做哪件事、由谁来做、是否继续深入都成为有意义的选择？
3. **最后看专长的作用。** 专长怎样改变做法或结果，才能增加选择，同时保留其他玩家参与同类行动的价值？是否需要专长专属牌、是否允许多专长同时生效，可以另行比较。
