# 游戏流程总览

> 记录一局完整游戏的循环、主要阶段及其衔接关系。

## 流程层级

游戏流程由地图、区域和节点三个层级组成：

- 地图：一局游戏的完整路线结构；
- 区域：组成地图的中间层，包括参与随机生成的普通区域和结构固定的特殊区域；
- 节点：玩家实际选择进入并处理内容的最小单位。

探索与战斗属于节点内部的处理阶段，不作为独立的地图层级。

地图结构、区域推进、节点分类及信息公开规则见《01-地图与区域设计》。

## 游戏流程边界

一局游戏具有以下两种结束方式：

- 玩家进入特殊终点节点并战胜最终 Boss 时，本局游戏成功结束；
- 游戏进行期间，若己方所有玩家角色死亡，本局游戏失败结束。

> 游戏开始时的角色、职业、专长、装备及其他初始状态，留待对应系统确定。

## 整局游戏循环

整局流程由开局准备、区域选择、节点选择及节点内的探索或战斗循环组成。行动产生的收益、消耗与状态变化，会影响队伍后续的构筑调整和路线选择。

### 开局流程

1. 组建队伍；
2. 选择难度；
3. 进入本局游戏，依次进入特殊起点区域和特殊起始节点；
4. 各玩家选择角色的初始职业与专长，并按角色系统规则获得对应的初始配置；
5. 公开地图主题、区域分布、区域规模及完整连接路线，进入区域选择循环。

### 区域选择循环

1. 观察地图路线、区域分布与区域规模；
2. 评估当前队伍状态与构筑；
3. 从当前区域的后继区域中选择一个进入，最多进行三选一；
4. 公开所选区域的节点数量与具体类型，进入节点选择循环；
5. 离开区域时，结合区域内行动产生的变化，重新评估并选择后继区域。

### 节点选择循环

1. 观察当前区域内的节点类型、节点数量与可用情况；
2. 评估当前队伍状态与构筑，选择进入节点或离开区域；
3. 进入节点后，根据节点内容进行探索或战斗；
4. 处理行动过程中产生的结果，若有奖励，则在离开节点前完成奖励处理；
5. 在允许的时机进行成长与配置调整，并依据变化后的状态与构筑选择下一个节点；
6. 离开区域时，返回区域选择循环。

### 探索循环（单回合）

1. 观察节点内可交互的探索内容；
2. 结合角色当前状态与手牌，评估可执行的探索行为；
3. 未处于交互过程时，可以在出牌前进行成长与配置调整；
4. 选择交互内容并打出手牌进行探索；
5. 处理探索结果、卡牌效果及补牌；
6. 根据变化后的状态、手牌与探索内容重新判断，继续行动或结束探索回合。

成长与配置调整不要求等到回合或节点结束，但各项操作仍须满足自身条件，槽位强化仍只能在提供对应功能的事件中进行。

### 战斗循环（单回合）

1. 观察敌方状态与行动信息；
2. 结合角色当前状态与手牌，评估可执行的战斗行为；
3. 选择手牌、目标并出牌；
4. 处理卡牌效果与战斗结果；
5. 根据变化后的战场状态与手牌重新判断，继续行动或结束己方回合，并按战斗规则推进。

探索或战斗结束后，返回节点层面的结果与奖励处理。游戏进行期间，若己方所有玩家角色死亡，本局立即失败结束；战胜最终 Boss 时，本局成功结束。

> 探索与战斗的具体行动限制、回合结束条件及回合衔接方式留待对应玩法设计。

## 节点阶段衔接

节点类别与其内部采用的处理阶段相互独立。具体分类见《01-地图与区域设计》。

进入探索节点后，游戏进入探索阶段。探索节点可能因事件或玩家的探索行为转入战斗阶段。

战斗节点与特殊终点节点采用战斗阶段规则。在战斗结束前，玩家不能主动退出当前节点。

## 节点结果与奖励

探索或战斗过程中可以直接产生结果，并对角色、卡牌或其他游戏状态造成影响。节点结果无须统一留到节点结束时结算，其具体生效时机由节点内容决定。

若节点产生奖励，玩家需要在离开节点前完成奖励处理。处理完成后，玩家才能离开当前节点并继续推进。

> 奖励的类型、归属、选择方式及放弃规则尚未确定。

## 游戏结束

玩家战胜最终 Boss 时，本局游戏成功结束；己方所有玩家角色死亡时，本局游戏失败结束。

> 游戏结束后的统计、结算及跨局保留内容留待后续设计。
