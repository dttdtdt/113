# 游戏流程总览

> 记录一局完整游戏的循环、主要阶段及其衔接关系。

## 流程层级

游戏流程由地图、区域和节点三个层级组成：

- 地图：一局游戏的完整路线结构；
- 区域：组成地图的中间层，包括参与随机生成的普通区域和结构固定的特殊区域；
- 节点：玩家实际选择进入并处理内容的最小单位。

探索与战斗属于节点内部的处理阶段，不作为独立的地图层级。

地图结构、区域推进、节点分类及信息公开规则见[地图与区域设计](./01-地图与区域设计.md)。

## 整局游戏循环

整局流程由开局准备、区域选择、节点选择及节点内的探索或战斗循环组成。行动产生的收益、消耗与状态变化，会影响队伍后续的构筑调整和路线选择。

### 开局流程

1. 组建队伍；
2. 选择难度；
3. 进入本局游戏，依次进入特殊起点区域和特殊起始节点；
4. 各玩家选择角色的初始职业，并按[角色系统规则](../character-system/00-角色系统总览.md)获得初始配置；
5. 公开地图主题、区域分布、区域规模及完整连接路线，进入区域选择循环。

### 区域选择循环

1. 观察地图路线、区域分布与区域规模；
2. 评估当前队伍状态与构筑；
3. 从当前区域的后继区域中选择一个进入，最多进行三选一；
4. 公开所选区域的节点数量与具体类型，进入节点选择循环；
5. 离开区域时，结合区域内行动产生的变化，重新评估并选择后继区域。

### 节点选择循环

1. 观察当前区域内的节点类型、节点数量与可用情况；
2. 评估当前队伍状态与构筑，选择进入节点或离开区域；
3. 进入节点后，根据节点内容进行探索或战斗；
4. 按节点规则处理行动结果与奖励；
5. 在允许的时机进行成长与配置调整，并依据变化后的状态与构筑选择下一个节点；
6. 离开区域时，返回区域选择循环。

### 探索循环

1. 查看节点内的交互目标，以及行动所需的能量、可能的结果和风险；
2. 结合角色状态、剩余探索能量和队伍目标，确定行动、目标及执行角色，由该角色执行；
3. 按行为规则进行适用的能力检定与结果抽选，处理行动结果并更新角色、物资和场景状态；
4. 根据行动结果，决定继续探索、在允许时离开节点，或结束当天的探索并休息。

行动、休息与天数推进规则见[探索与生存设计](./02-探索与生存设计.md)。

玩家可以在两次行动之间进行成长与配置调整。各项操作仍须满足自身条件，槽位强化只能在提供对应功能的事件中进行。

### 战斗循环（单回合）

1. 观察敌方状态与行动信息；
2. 结合角色当前状态与手牌，评估可执行的战斗行为；
3. 选择手牌、目标并出牌；
4. 处理卡牌效果与战斗结果；
5. 根据变化后的战场状态与手牌重新判断，继续行动或结束己方回合，并按战斗规则推进。

战斗结束后，按节点阶段衔接规则继续推进。

> 战斗的具体行动限制、回合结束条件及回合衔接方式留待对应玩法设计。

## 节点阶段衔接

节点类别用于标记进入前可见的内容类型。当前处理阶段决定队伍在节点内使用探索规则还是战斗规则。具体分类见[地图与区域设计](./01-地图与区域设计.md)。

进入探索节点后，队伍先按探索阶段规则行动。若事件或探索行为触发战斗，队伍转入战斗阶段。战斗结束后，按节点内容继续探索或处理节点结果。

进入战斗节点或特殊终点节点后，队伍按战斗阶段规则行动。战斗进行中，队伍不能主动离开当前节点。

## 节点结果与奖励

探索和战斗中的行动结果可以即时生效，例如改变角色状态、卡牌或场景。具体生效时机由节点内容决定。

节点产生的奖励须在离开前处理完毕。

卡牌奖励的来源和归属遵循[卡牌共通生命周期](../card-system/01-卡牌共通生命周期.md)。奖励的具体内容、选择方式和放弃规则由对应来源设计。

## 游戏结束

- 队伍在特殊终点节点战胜最终 Boss，本局胜利。
- 游戏进行期间，己方所有玩家角色死亡，本局立即失败。

> 游戏结束后的统计、结算及跨局保留内容留待后续设计。
