# 113

Unity 项目位于 [FX113A1](./FX113A1/)，使用 Unity `6000.3.29f1`。

通过 Unity Hub 打开该目录，在编辑器打开 `Assets/Scenes/CardUIDemo.unity`，点击 Play 可验证卡牌生成、费用刷新及视图回收。

Godot 原框架、UI 与旧工程内容的迁移和清理已经完成；尚未实现的战斗规则仍属于后续功能开发。

迁移范围、验证结果与清理记录见 [迁移总览](./Docs/unity-migration/00-迁移总览.md)。[ArtResource](./ArtResource/) 保留美术原始文件。
